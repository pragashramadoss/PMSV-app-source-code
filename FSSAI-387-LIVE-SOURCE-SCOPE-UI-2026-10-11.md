# PMSV FSSAI Helper — 387 verified official source scope checks wired into the visible product screen

**Date:** 11 October 2026. GitHub `gh-pages` only. WordPress unchanged.

The existing source-review matrices total **103 + 284 = 387** conditional/nontransfer checks for **at least 84** distinct unresolved catalogue identities. They previously existed as audit/export data but were not available for inspection in the actual product screen.

This update loads both matrices beside the official FSSAI Version IX source master. For each of the remaining **121 first-exact-source unresolved identities**, the new collapsed review panel displays only the checks for that exact catalogue ID. Every source reference is validated at runtime for metal, **full named article**, exact **numeric value and unit**, with no automatic finished-food assignment.

The panel is **REVIEW ONLY / NOT APPLIED**. The source reference is never interpreted as a finished-product MRL, laboratory compliance PASS or permission. The entire panel is withheld when a source row, loaded matrix count, illegal approval flag or product identity mismatches. The existing first-source ledger remains **533 = 412 partial + 121 unresolved**, **0 complete compliance approvals**.

Reference: [FSSAI Contaminants Version IX (03.02.2026), §2.1](https://fssai.gov.in/upload/uploadfiles/files/Comp_Contaminants_Regulations_03_02_2026_IX.pdf).
