# R103 · R&D recipe requests

Open **Product finder → R&D recipe requests** to copy the outstanding questions or download an Excel-compatible CSV. The first column identifies the SKU, catalogue food and approved recipe revision. The second lists affected artworks and pack levels. The third contains every requested recipe detail for that group.

## Adding a request

1. Open a product worksheet and expand **Packaging, labelling and claims → Ingredient percentage on artwork**.
2. Enter the SKU, artwork revision, pack and ingredient. Record what the available formulation and supplier documents establish. Add other questions in **Other recipe details needed from R&D**, one per line. For example, ask R&D to confirm the order of two emulsifiers in the approved formula.
3. Select **Save artwork check**. Questions appear in the product finder as soon as the check is saved. New questions can be saved while the formula revision is still pending.
4. When R&D replies, open the saved check, enter the evidence and clear any answered free-text questions. Save the update to refresh the request. The product brief and the full product register also include open questions.

## How requests are grouped

Within a catalogue product, artwork checks sharing an SKU and an approved formula revision contribute to the same request. The helper lists each affected artwork and asks an identical question once per group. If the formula revision is unknown, each artwork revision and pack level keeps its own group. Ingredient-specific questions retain the ingredient name. The request reflects what has been recorded on each saved artwork check.

For an unknown fruit ingredient, the request asks whether the formula uses fruit, added flavour, both or neither. When a quantity needs checking, it can ask for the ingoing batch, direct additions, or the fruit share and supplier specification for a preparation. Fully recorded flavour-only or absent-ingredient cases generate no automatic request for fruit quantities. Issues such as an inaccurate printed percentage or a misleading image stay in the artwork findings. Reviewers can add a specific R&D question in either case.

The original regulatory interpretation, page references and numerical comparison are in the [R102 ingredient percentage review](catalogue-ingredient-percentage-review-r102.md). The request helps collect evidence for that review.

Saved R102 artwork checks are readable in the same browser storage location. A separately named offline HTML file may have its own browser storage. To continue existing local work, keep the original file path and browser profile when updating. When browser storage is unavailable, the request includes checks kept in the open session. Download or copy the request before closing the session.
