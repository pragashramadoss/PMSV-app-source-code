# R106 · Batch code and manufacturing site

Open **Product worksheet → Packaging, labelling and claims → Batch code and manufacturing site**. Enter the SKU, artwork revision, pack and actual batch code. Use the site master revision that applied to that SKU and lot. A site’s ability to make another product or its appearance on an older artwork does not establish its assignment here.

## Entering the evidence

| Input | What to enter |
| --- | --- |
| Batch and prefix length | Transcribe the complete lot code and enter the number of leading characters used by the approved coding instruction. The comparison preserves case, punctuation and leading zeros. A two-character prefix is an available company coding choice. |
| SKU site master | Paste four tab-separated spreadsheet columns or use vertical bars in the order **prefix, site, FSSAI licence, status**. Use one prefix per row. Use **approved**, **retired** or **excluded** for the revision being reviewed. Retired and excluded rows may have a blank licence when the historical number is unavailable. |
| Production or packing record | Enter the independent lot-record reference and the operator licence shown by that evidence. A prefix can identify a candidate site even while this check is open. |
| Printed or decoded information | For a single explicitly identified operator, enter its licence. For a multi-site legend, paste **prefix and licence** on each line. Transcribe the codes actually shown, including obsolete ones. For a QR or barcode, also identify the decoded evidence. |
| Individual wrapper and retail outer | If relying on the outer for the number, enter its artwork revision and licence data. The helper looks for a saved **Small-pack declarations** check with the same SKU, inner artwork, operator role and retail outer. It displays the recorded measurement and the existing Gazette wording note. The placement finding reflects the current saved pack check. |

For example, a fictional batch **01X27** gives **01** when the documented width is two. If the SKU master maps **01** to Site North and the batch record gives that site’s licence, compare that number with the printed or decoded declaration. If the legend also lists a retired code for Site West, the worksheet flags Site West even when the selected batch correctly maps to Site North. An approved site omitted from the legend is reviewed for the selected batch only. A common label need not mechanically list every entry in the supplied company master for this comparison.

## Reading the result

- **Batch, site and operator licence agree** means the documented batch assignment, production record and applicable operator-licence evidence agree for this check. The result concerns the transcribed records. Current licence status, licensed activities, product endorsement and premises can be checked through FoSCoS. [FoSCoS operator search](https://foscos.fssai.gov.in/advance-fbo-search)
- **Differences to resolve** identifies a conflicting number, duplicate prefix, retired or excluded assignment, or a legend missing the selected batch prefix. The export identifies the evidence source and the particular code or number to investigate.
- **Evidence or placement to review** identifies an unmatched prefix, missing independent record, an unreadable or generic code used as the only evidence, an unclear operator role, or reliance on a corresponding outer. The worksheet distinguishes a 14-digit licence beginning with 1 from a 14-digit registration beginning with 2. Registration cases require their own assessment. [FSSAI licensing FAQ 43](https://www.fssai.gov.in/upload/uploadfiles/files/FAQs_Licensing_Registration_26_07_2022.pdf)

Regulation 5(9) addresses lot identification. The definition in 2(1)(l) describes identification for tracing manufacture and distribution. Regulation 5(7)(b) separately addresses the brand owner’s licence and, as applicable, the licence of a different manufacturer, marketer, packer or bottler. The company prefix identifies a row in its own records. The licence declaration and its placement are checked separately. [Labelling and Display Regulations, pp. 2 and 16](https://www.fssai.gov.in/docs/food-law/regulations/Comp_Labelling%20Display_Version%20VIII_09_09_2025.pdf#page=2) · [Licence and lot provisions, p. 16](https://www.fssai.gov.in/docs/food-law/regulations/Comp_Labelling%20Display_Version%20VIII_09_09_2025.pdf#page=16)

Under regulation 8(5)(b), a different operator’s number can be supplied through the specified barcode route. FAQ 43 includes QR codes. Enter the number associated with this operator or the decoded mapping for the lot. A generic URL or a collection of unassigned numbers leaves the identity open. When the site operator is the brand owner, the helper checks the printed licence or the separately documented small-pack route. [Regulation 8(5), p. 22](https://www.fssai.gov.in/docs/food-law/regulations/Comp_Labelling%20Display_Version%20VIII_09_09_2025.pdf#page=22) · [FAQ 34, pp. 5–6](https://www.fssai.gov.in/upload/uploadfiles/files/FAQ_Labelling_Display_01_11_2023.pdf#page=5) · [FAQ 43, p. 7](https://www.fssai.gov.in/upload/uploadfiles/files/FAQ_Labelling_Display_01_11_2023.pdf#page=7)

**Save batch/site check** retains the site list and evidence for this lot on the device. **Start another batch from this site list** carries the SKU, artwork, operator role and master into a fresh check. Enter new batch, production and artwork observations for the next lot. Saved findings appear in the product brief, the batch/site CSV and the 533-product register. The new workflow starts with an empty site list. Legal sources checked on 21 November 2026.
