Import canonical 35-case register

Accepts CSV with unique case_id (or id/catalog_id), product (or name), and priority. Exactly 35 distinct cases are mandatory. Uploaded PASS values are ignored; every case is controlled as HOLD.

Import original historical IDs and owners only; never invent missing identifiers. Requires every one of the 35 cases × five gates to be mapped exactly once. An import verifies structure, not provenance or sign-off.

Safety boundary: recorded documentation is not verified evidence. A reviewer must check originals, scope, matrix, method, laboratory accreditation, sample/lot traceability and QA authorization in the controlled system. Local browser storage is not a secure audit trail.

FSSAI has two separately published manuals that reuse method codes 09.001–09.007 for different titles. Use document + complete procedure title + edition + laboratory SOP; the code alone is ambiguous. These are bibliographic crosswalks, not automatic approval of method applicability.
